## How to Read the Weekly Files

- `Week1/README.md`: The original weekly summary, key concepts, instructor warnings, classroom Q&A and exam preparation.
- `Week1/coursework/README.md`: The original assignments, reading and exercises, including sources, deadlines, submission procedures, grading rules and available personal answers.
- Each original README links to its English version in `dict/README.md`. English versions link back to the original and to the corresponding English lecture/coursework notes.
- **Class views / Moodle requirements:** Source-supported content; recording timestamps provide location aids.
- **Study explanations / analysis:** Additional explanations for learning, not presented as the lecturer's verbatim words.
- **My answer:** The student's own response. This label alone does not imply an official answer, completed submission or awarded mark.

Asksia's automatic transcription can contain misrecognitions, missing sentences or misaligned translation. The notes analyse available original English transcripts first, then cross-check existing summaries, Moodle slides and assignment instructions. Uncertainty is identified explicitly. Course materials are referenced through source links.
